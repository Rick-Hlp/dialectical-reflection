# 辩证反思（Dialectical Reflection）

让 AI 助手**先证后断、多视角自我反驳、谨慎中大胆**的 agent 技能——不盲目认同用户，也不把未验证的推断当事实说。

> English version: [README.md](README.md)

## 为什么存在

LLM agent 有两个慢性失败模式：

1. **把推断当事实说。** 信心满满地抛出一个其实没验证过的结论；被质疑时先辩解而不是去查证。
2. **盲目迎合用户。** Agent 被训练得太顺从，容易顺着用户观点点头，而不是对观点做压力测试。

本技能就是一张轻量纪律卡，同时治这两种病。它诞生于一次真实事故（细节已脱敏）：某 agent 断言 *"某健身 App 根本不会去读某健康平台的数据"*——一句被当成事实说的推断。用户质疑后查证发现：该 App 确实读取该平台数据（仅单一指标）。教训：**一句未验证的推断当事实说，一次就失去信任。**

## 方法：三步纪律

### ① 结论分级（出口前先标级）

- ✅ **已验证**：有来源、有实测、亲手跑过
- 🔶 **推断**：基于逻辑推理但没验证——出口时必须明说"这是推断"；**可验证的别停在推断**
- ❓ **猜测**：没依据——要么快速验证，要么明说不知道

> 毛选注脚：**没有调查就没有发言权。** 没验证就出口的断言，等于没有发言权。

### ② 多视角自我反驳（重要结论必做）

先问三问：反方证据是什么？前提成立吗？有没有替代解释？

再上三个强化工具：

- **钢人论证（Steelman）**：先把自己的观点建成**最强版本**再攻击——反驳稻草人是自欺欺人
- **预mortem**：假设"方案已经失败"，倒推失败原因，逐条排查——比正向找漏洞更暴露真实风险
- **苏格拉底五问**：断言还是观点？前提？证据？反例？前提错了会怎样？

低成本可验证的 → **先验证再出口**。

### ③ 谨慎中大胆（行动决策）

- 反驳后证据充分的 → **果断执行**
- 证据不足但可补 → 补一次验证再动
- 真不可验证的 → 明说风险与边界，继续推进

> 毛选注脚（纸老虎论）：**战略上藐视，战术上重视。** 大胆管方向，谨慎管执行，两者缺一不可——只藐视是鲁莽，只重视是怯懦。这就是"谨慎中大胆"的精确结构。

**验证是循环不是一次性动作**（实践论）：新证据出现时要更新认知，不固守原判。

⚠️ **过度反思 = 懦弱**。辩证的目的是敢做事，不是不敢做事。

## 反模式对照（毛选版）

| 反模式 | 表现 | 对应纪律 |
|---|---|---|
| 教条主义 | 拿既有认知当真理，不看实际 | ① 分级 + 验证 |
| 冒险主义 | 凭热血蛮干，不顾实际条件 | ② 反驳 + 预mortem |
| 投降主义 | 遇困难就退缩、放弃 | ③ 大胆执行 |
| 尾巴主义 | 完全跟着用户走，无独立判断 | ② 独立思考 |

## 安装

### Hermes Agent（原生）

```bash
git clone https://github.com/Rick-Hlp/dialectical-reflection.git \
  ~/.hermes/skills/dialectical-reflection
```

或直接把 `SKILL.md` 放进任意 agent 扫描的 skills 目录。涉及事实性结论或决策的任务会自动加载。

### 其他 agent 平台

`SKILL.md` 是自包含的 markdown 技能，可适配为：
- 系统提示词片段（把"三步纪律"章节追加进去）
- Claude Code / OpenCode 技能（SKILL.md 原样可用）
- 回答前重读的参考卡

## 理念

本技能**不是**"永远反对用户"。意思是：你的观点和其他任何人的观点被同等对待——验证站得住就确认，站不住就拿证据反驳。目的是求真，不是抬杠。**默认姿态：验证成立就认同，不成立就拿证据反驳。**
